# Flowe

Интерактивная версия исходного цветка: пять равных эллипсов и оригинальный белый знак, встроенный заподлицо в верхний синий лепесток. Статическая страница `/flowe/`; сервер и внешние API не нужны. Исходная сетка с пазом экспортирована из Blender V3, без изменения формы.

## Управление студией

Мышь / один палец вращают сцену, колесо / два пальца меняют масштаб. Правая кнопка с перетаскиванием сдвигает кадр. В фокусе области 3D стрелки вращают, `+` / `−` меняют расстояние, `0` возвращает общий ракурс.

Вверху панели — демонстрации и выбор лепестка 1–5. Выбрать лепесток можно также нажатием на модель. Изменения существуют в текущей вкладке; после перезагрузки возвращаются исходные значения. Сохранения состояния в проекте раньше не было; эта версия его не добавляет.

- **Геометрия.** Сохранены «Цветок / Слои / Веер». Раскрытие −45…100%, расстояние −110…150%. Шаг центров равен `0.44 + layers × 0.0075`: около −58.67% слои совпадают по высоте, ниже меняют порядок. Форма не исчезает из-за сортировки целых объектов. Есть индивидуальные поворот и смещение по высоте.
- **Цвет и смешивание.** Палитры и цвет каждого лепестка; прохождение света, Normal/Alpha, Add, Screen, Multiply, Overlay. Сила художественного смешивания независима от поглощения. При выборе художественного режима поглощение начинается с нуля и может быть добавлено вручную. Multiply/Overlay на чёрном фоне закономерно темнеют. Add не ограничивается до тонального преобразования; Screen использует стандартную формулу в диапазоне 0…1 и сохраняет HDR-избыток.
- **Материал.** «Стекло / Матовое / Эмаль» — пресеты. Общие параметры и переопределения выбранного лепестка: Base Color, Opacity, Transmission, Roughness, IOR, оптическая Thickness, Attenuation Color/Distance, SSS сила/цвет/радиус, Specular, Metalness, Coat/Roughness, Emission цвет/яркость. «Вернуть лепесток к общим настройкам» снимает его переопределения и отдельный базовый цвет. Общая правка не стирает индивидуальные переопределения остальных лепестков.
- **Свет.** Главный выключатель обнуляет ambient и отключает три внешних источника и окружение, включая отражения. Фон и экспозиция независимы. Каждый источник имеет тип, включение, цвет, интенсивность, азимут, высоту и расстояние, цель направления. Направленный / прожектор поддерживают карты теней, площадной — размер блика; точечный — затухание по расстоянию. Неприменимые регуляторы отключены.
- **Свечение.** Каждый лепесток независимо переопределяет общую эмиссию. Яркость материала, подсветка соседей и общий Bloom с радиусом/порогом/силой — отдельные настройки. «Использовать общую эмиссию» возвращает наследование.
- **Логотип.** Можно скрыть знак или переместить от −12 до +4 относительно поверхности. При скрытии/перемещении паз заменяется цельной исходной сеткой эллипса. Цвет, Opacity, Roughness, Emission и подсветка соседей независимы от лепестков.
- **Камера и фокус.** Перспектива и ортография; три четверти, сверху, спереди, сбоку, крупный план. Объектив 14–200 мм меняет реальный FOV, расстояние отдельно меняет перспективу. Опция сохранения размера компенсирует объектив перемещением камеры в пределах её диапазона. DOF: f-stop, фокусная дистанция, предел размытия. «Выбрать фокус» временно отключает OrbitControls, один клик/тап ставит фокус по raycast; Esc отменяет. В списке доступны все пять лепестков и логотип, в том числе за стеклом. Удержание привязывает точку к локальным координатам объекта и пересчитывает её глубину при вращении. Масштаб оптики: 1 единица = 10 см. Для ортографии физический DOF отключён.

Все числовые параметры имеют слайдер и точное поле. Каждый раздел сбрасывается отдельно; общий сброс восстанавливает исходную сцену. Демонстрации: синее и цветное стекло, матовое рассеивание, один светящийся лепесток, светящийся логотип внутри цветка.

## Рендер и ограничения

Three.js 0.180.0 / WebGL 2 с `EXT_color_buffer_float`. Шесть исходных сеток рендерятся независимо в HDR-буферы цвета и нормали/глубины. В композиционном шейдере они сортируются по глубине **в каждом пикселе**, с детерминированным разрешением совпадающих глубин. Полупрозрачные поверхности не используют обычную сортировку по центрам объектов. Затем выполняются DOF, многомасштабный Bloom и один ACES-fit / linear-to-sRGB. Художественное смешивание и эмиссия работают до этого преобразования.

Это интерактивный растровый инструмент, не Arnold/Redshift и не path tracer:

- Для каждого объекта хранится ближайшая поверхность, а не все границы объёма. Прохождение света, окраска и экспоненциальное поглощение — модель тонких слоёв. Нет каустик, многократных отражений, полного внутреннего отражения или точного пути луча через пересекающиеся объёмы.
- IOR меняет Френель и небольшое экранное смещение проходящего изображения; шероховатость размывает свет от нижних слоёв через mip-уровни. Экранное преломление ограничено доступной видимой геометрией. Thickness — оптическая толщина; она не масштабирует исходную сетку.
- SSS — окрашенное расширенное распределение прямого света с затуханием по радиусу/толщине. Нет физического объёмного случайного блуждания.
- Эмиссия подсвечивает соседей двумя точечными источниками сверху/снизу каждого объекта. Это независимый от Bloom вклад. Он не рассчитывает непрямые переотражения и точную окклюзию света, поэтому возможны утечки. Сам светящийся объект при этом корректно закрывается непрозрачными поверхностями в основном изображении.
- DOF — экранное размытие с дисковой выборкой по ближайшей видимой глубине. В одном пикселе за прозрачными слоями нет нескольких независимых дистанций резкости. Возможны ореолы на сложных прозрачных границах и дискретность при очень большом размытии. Bloom применяется после DOF.
- Площадные и вспомогательные emissive-источники не отбрасывают физические мягкие тени; карты теней доступны направленному и прожектору. Матовые/непрозрачные лепестки отбрасывают тени, прозрачные не создают цветные каустики.

«Быстро / Баланс / Высокое» ограничивают длинную сторону внутренних буферов просмотра до 720 / 1100 / 1600 пикселей. Рендер выполняется по изменениям, при вращении — каждый кадр. Сохранение использует тот же pipeline при полном размере 1920/2560; на слабом устройстве предпочтительнее 1920. PNG поддерживает прозрачный фон и полупрозрачный Bloom, JPEG — выбранный фон. Маркер фокуса и интерфейс в файл не попадают. Незначительные отличия краёв/фильтрации при другом разрешении возможны.

## Проверка

`tests/studio.browser.cjs` проверяет реальный Chrome/WebGL: три композиции с глубоким пересечением и повторяемость кадра, красный+синий/зелёный во всех режимах, тёмную сцену без света, вклад эмиссии в соседей, скрытие/просвечивание погружённого логотипа, влияние материальных параметров на пиксели, типы/положение света, FOV, ортографию, клики фокуса и его удержание, диафрагму, PNG/JPEG и мобильный интерфейс. Тест требует установленный Playwright и Chrome; установка не входит в production.

```sh
FLOWE_PLAYWRIGHT=/path/to/node_modules/playwright \
FLOWE_URL=http://127.0.0.1:8087/flowe/ \
FLOWE_QA_DIR=/tmp/flowe-studio-qa \
node tests/studio.browser.cjs
```

## Скачивание исходников

Внизу панели доступен раздел «Скачать исходную модель». `downloads/flowe-blue.blend` — исходная синяя Blender-сцена с логотипом, материалами, светом и камерой крупного плана. `downloads/flowe-obj.zip` — OBJ, MTL и инструкция: пять отдельных лепестков и знак, без света и камер. OBJ передаёт базовые материалы; для точного стекла используется BLEND.

Это постоянные исходники, а не экспорт текущих настроек редактора. Ссылки работают независимо от WebGL и JavaScript. Файлы скопированы из проверенных `flower_blue_logo_closeup.blend` и `flowe_obj.zip` без изменения содержимого.

## Файлы и сборка

`app.mjs` — сцена, взаимодействия и экспорт; `studio/state.mjs` — состояние и пресеты; `studio/ui.mjs` — формы и наследование; `studio/renderer.mjs` — HDR-композитор, SSS, DOF и Bloom; `app.bundle.js` — готовая локальная сборка Three.js 0.180.0 и OrbitControls / RoomEnvironment, `assets/flower.json` — шесть сеток с координатами, нормалями и индексами. Оси модели преобразованы из Blender Z-up в Three.js Y-up; размеры сохранены. Логотип и его паз принадлежат одной группе трансформации. Для варианта без логотипа используется копия целой сетки голубого лепестка, повёрнутая до ориентации синего: все пять эллипсов одинаковые. Обе сетки переиспользуются при переключении.

Для изменения JS установите Node.js 20+ и выполните из этой папки:

```sh
npm ci
npm run build
```

Для локального просмотра из корня сайта: `python3 -m http.server 8087`, затем `http://localhost:8087/flowe/`.

Шрифты Manrope хранятся локально, SIL OFL в `assets/OFL.txt`. Three.js — MIT, `THREE-LICENSE.txt`. По запросу владельца опубликованы исходная Blender-сцена этого цветка и её OBJ-экспорт. Остальные материалы проекта не публикуются.

API-справка: [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html), [WebGLRenderTarget](https://threejs.org/docs/pages/WebGLRenderTarget.html). Версия библиотеки закреплена в package-lock.json.
