# Flowe

Интерактивная версия исходного цветка: пять равных эллипсов и оригинальный белый знак, встроенный заподлицо в верхний синий лепесток. Статическая страница `/flowe/`; сервер и внешние API не нужны. Исходная сетка с пазом экспортирована из Blender V3, без изменения формы.

## Управление

- Мышь / один палец: вращение. Колесо / два пальца: масштаб. Правая кнопка / два пальца с перемещением: сдвиг кадра.
- В фокусе области 3D: стрелки вращают, `+` / `−` меняют масштаб, `0` возвращает общий ракурс.
- «Цветок», «Слои», «Веер» меняют композицию; ползунки уточняют раскрытие, расстояние и закручивание. Раскрытие и расстояние между слоями доступны от −20% до 100%: отрицательные значения сближают лепестки и позволяют слоям частично пересекаться.
- Выберите лепесток кнопкой 1–5 или нажатием на модель. Поворот, высота и цвет редактируются независимо. Логотип перемещается вместе с синим лепестком.
- «Логотип на лепестке» в разделе «Композиция» скрывает или возвращает знак. Без знака верхний лепесток становится цельным эллипсом без паза; выбор сохраняется при смене материала, палитры и композиции, учитывается в PNG/JPEG. Общий сброс возвращает логотип.
- «Логотип» приближает текущую позицию знака; при скрытом знаке этот ракурс называется «Крупно». «Сбросить» восстанавливает всю сцену. На телефоне сброс находится под настройками.
- «Сохранить кадр» экспортирует текущий ракурс без интерфейса в PNG/JPEG; 1920 или 2560 пикселей по длинной стороне. Соотношение сторон совпадает с областью 3D. Прозрачный фон доступен только в PNG. Настройки существуют в текущей вкладке, после перезагрузки возвращаются исходные.

## Скачивание исходников

Внизу панели доступен раздел «Скачать исходную модель». `downloads/flowe-blue.blend` — исходная синяя Blender-сцена с логотипом, материалами, светом и камерой крупного плана. `downloads/flowe-obj.zip` — OBJ, MTL и инструкция: пять отдельных лепестков и знак, без света и камер. OBJ передаёт базовые материалы; для точного стекла используется BLEND.

Это постоянные исходники, а не экспорт текущих настроек редактора. Ссылки работают независимо от WebGL и JavaScript. Файлы скопированы из проверенных `flower_blue_logo_closeup.blend` и `flowe_obj.zip` без изменения содержимого.

## Файлы и сборка

`app.mjs` — редактируемый исходный JS, `app.bundle.js` — готовая локальная сборка Three.js 0.180.0 и OrbitControls / RoomEnvironment, `assets/flower.json` — шесть сеток с координатами, нормалями и индексами. Оси модели преобразованы из Blender Z-up в Three.js Y-up; размеры сохранены. Логотип и его паз принадлежат одной группе трансформации. Для варианта без логотипа используется копия целой сетки голубого лепестка, повёрнутая до ориентации синего: все пять эллипсов одинаковые. Обе сетки переиспользуются при переключении.

Для изменения JS установите Node.js 20+ и выполните из этой папки:

```sh
npm ci
npm run build
```

Для локального просмотра из корня сайта: `python3 -m http.server 8087`, затем `http://localhost:8087/flowe/`.

Свет и преломление рассчитаны в реальном времени через WebGL 2 / MeshPhysicalMaterial, а не Cycles. Для каждого слоя строится отдельный буфер преломления нижележащих лепестков. Передача света остаётся приближённой, каустики не рассчитываются. Экспорт имеет ту же визуализацию, что и браузер. Потеря WebGL-контекста показывает сообщение с перезагрузкой.

Шрифты Manrope хранятся локально, SIL OFL в `assets/OFL.txt`. Three.js — MIT, `THREE-LICENSE.txt`. По запросу владельца опубликованы исходная Blender-сцена этого цветка и её OBJ-экспорт. Остальные материалы проекта не публикуются.
