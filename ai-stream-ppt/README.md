# AI Stream · галерея презентаций

Статический маршрут /ai-stream-ppt/. Из корня сайта: `python3 -m http.server 8769 --bind 127.0.0.1`; открыть http://127.0.0.1:8769/ai-stream-ppt/. У слайдов есть прямые адреса: например, `#deck/2`.

- [Страница шаблонов Figma](https://www.figma.com/design/CSJO6EHIsKkp0TfBQavCxt/AI-STREAM-PP?node-id=152-610). В `covers.js` указаны и кадр обложки, и раздел, который открывается в Figma.
- [Презентация Figma](https://www.figma.com/design/CSJO6EHIsKkp0TfBQavCxt/AI-STREAM-PP?node-id=1537-2). 20 слайдов, экспорт 10.11.2026. `slides.js` содержит HTML слоёв и текст для режима чтения. Оригинальные иллюстрации и вставленные миниатюры лежат в `assets/`; соответствия — в `assets/slide-sources.json`. Изображение экспоната «ИИ-стрим презентаций» экспортировано из 1537:3.
- [Референс каркасного зала](https://ru.pinterest.com/pin/355573333094323416/) использован для геометрии и движения. Медиа Pinterest в страницу не входят.
- `app.js` строит перспективу зала, маршрутизацию, просмотр слайдов, анимации и две диаграммы на основе исходных показателей. Вставленные миниатюры открываются как изображения.
- Оригинальные локальные выгрузки и сборщик слайдов находятся вне репозитория в `../ai-stream-build/`. Шрифты Inter и JetBrains Mono поставляются локально с лицензиями SIL OFL.

Страница публикуется по прямой ссылке. Поисковая индексация отключена через `noindex`.
