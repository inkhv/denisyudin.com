# The Genius List

Public route: https://denisyudin.com/TheGeniusList/ (capitalization intentional).

A complete Russian analysis of all 55 The Genius List interviews: 001–007 brief, 008–055 detailed, followed by 14 cross-interview principles, 10 applied methods, an AI example and five antipatterns. Research checked 10 October 2026. Interpretations and proposed practices are explicitly distinguished from primary sources.

Static HTML/CSS/JS. Edit these files directly. The article inherits the editorial palette and Manrope typography of `/pair/`. Full text and links work without JavaScript; JavaScript adds name/role/topic search in the 55-person index, active section navigation and mobile contents collapse. Search never hides the article text. No storage, analytics or external scripts. Google Fonts supplies Manrope as on `/pair/`.

`cover.png` is an original typeset sharing image, created from the article title using Manrope. It is not a portrait or an illustration from The Genius List.

Preview from the repository root: `python3 -m http.server 8768`, then open `/TheGeniusList/`. Check desktop/mobile navigation, existing and empty search results, reset, all 55 source links and anchor targets. Cache-bust CSS/JS on updates. Keep changes inside this directory; the home page and other articles are intentionally independent.
