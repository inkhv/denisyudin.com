# /liver-update/ — иммерсивная версия доклада о гипераммониемии

Та же содержательная часть, что в `/liver/`, но с 3D-сценами, моушен-дизайном и «эффектом присутствия».
`/liver/` не изменяется: на него ведёт QR-код на слайдах доклада. QR этой страницы (`qr.svg`) ведёт на
`https://denisyudin.com/liver-update`. Страница не связана с главной сайта, `noindex, follow`.

## Как устроено

Ритм страницы — **погружение → бланк**: у каждой главы сначала тёмная «сцена» (поле микроскопа, 3D),
затем белый лист с текстом и интерактивом из `/liver/`. Фирменный приём — тест связи чисел:
номера глав в шапке соединяет бордовая «линия пера»; в 3D она становится рельсом камеры, а в финале
путь через семь глав, увиденный спереди, складывается в силуэт печени (анаморфоза: каждая точка пути
лежит на луче из фронтальной точки в контур печени, но на своей глубине).

```
index.html      вся разметка и весь текст (работает без JS; сцены — декоративные, у каждой есть описание для скринридера)
styles.css      стили /liver/ + раздел «liver-update: погружение и бланк» в конце файла
main.js         роутинг по hash, «линия пера» в шапке, пейджер, выводы, View Transitions между главами
data.js         ДОСЛОВНО перенесённые константы /liver/app.js (FLOW, COHORTS, CYCLE, STUDIES, TAGNAME, CASE_Q, QUIZ, CASE_CHART)
ui/*.js         интерактив /liver/ по модулям; ui/scenes.js — режимы 3D, «Меньше движения», наклон; ui/motion.js — микро-моушен
gl/engine.js    один общий WebGLRenderer; canvas переносится в то окно (.gl-host), которое больше всего видно
gl/bridge.js    события интерфейса (lu:flow, lu:cycle, lu:route …) → состояние сцен
gl/bindings.js  параметры анимации, вычисленные из data.js (см. ниже)
gl/quality.js   уровни качества и проба FPS;  gl/loupe.js — лупа микроскопа;  gl/lib.js — шейдеры «тёмного поля»
gl/scenes/      hero (обложка), lobule (долька: главы 1 и 5), cycle (порочный круг), targets (органы-мишени), rail (путь глав и финал)
posters/        WebP-кадры каждой сцены: заглушка до загрузки 3D и замена 3D без WebGL / при пониженной анимации
vendor/         three.min.js — сборка three.js 0.186.1 только из используемых классов
fonts/          Literata, IBM Plex Sans, IBM Plex Mono (WOFF2, кириллица + латиница), SOURCE.md, лицензии OFL
tools/verify-data.mjs  сверка данных и текстов с /liver/
qr.svg, cover.png      QR на /liver-update и OG-обложка 1200×630
```

Событийная шина: `ui/core.js` → `emit('flow', {key})`, `on('cycle', fn)` и т. д. (`CustomEvent 'lu:*'` на `document`).
3D-слой ничего не знает о DOM интерактива и подписан только на эти события.

## Режимы сцен

Класс на `<html>` выставляется до первой отрисовки (встроенный скрипт в `<head>`):

- `gl-wait` — видны постеры, 3D грузится лениво (`requestIdleCallback` после первой отрисовки);
- `gl-on` — 3D работает; canvas один, переезжает в видимое окно, вне экрана и в скрытой вкладке рендер стоит;
- `gl-off` — только постеры и SVG-схемы `/liver/` (обложка — бланк ТСЧ из `/liver/`, круг — HTML-кольцо).
  Включается при `prefers-reduced-motion: reduce`, переключателе «Меньше движения» в шапке (`localStorage
  liver-update-calm`), режиме экономии трафика / 2G, отсутствии WebGL (проверка до загрузки three.js),
  потере контекста (`webglcontextlost`) или если даже при минимальном разрешении FPS < 20.

Уровни качества (`gl/quality.js`, принудительно: `?q=high|medium|low`):

| | high | medium | low |
|---|---|---|---|
| когда | десктоп: > 4 ГБ и > 4 ядер | телефон / сенсорный экран / ≤ 4 ГБ / ≤ 4 ядер | ≤ 2 ГБ или ≤ 2 ядер |
| DPR canvas, не более | 2 | 1,5 | 1 |
| частицы | 100 % | 70 % | 45 % |
| сглаживание, лупа | да, да | нет, да | нет, нет |

Затем проба FPS: если за 2 с меньше 42 кадров/с — разрешение canvas снижается ступенями ×0,75 до 0,75;
если и тогда меньше 20 — постеры. Постобработки (bloom, DOF) нет вовсе: свечение даёт аддитивный «краевой свет»
в шейдерах, фокус микроскопа — размытие кружков по глубине в шейдере и короткий CSS-blur canvas при смене сцены.

## Данные и привязка анимации

`data.js` — копия констант `/liver/app.js` без изменений. Сверка: `node liver-update/tools/verify-data.mjs`
(из корня репозитория; Node 22). Она сравнивает константы, 42 источника, все тексты разметки и строки JS с `/liver/`.
**Правка фактов:** сначала презентация и `/liver/`, затем те же правки в `data.js` / `index.html`, затем сверка.

Привязка (`gl/bindings.js`, всё вычисляется из `FLOW`):
- скорость «турбины» цикла мочевины = `FLOW[*].cap` (100 / 17 / 22 / 19 / 100 %);
- в норме печень извлекает 73 % портального аммиака: половина частиц превращается в мочевину (зона 1),
  половина — в глутамин (зона 3); доля превращения в мочевину масштабируется мощностью цикла;
- шунт: 65 % частиц идут по обходному сосуду; аммиак в ткани: ×5 при стеатозе, ×10 при НАСГ;
- глава 5: «ускорение турбины» под действием орнитина — только визуально, без процентов (подпись «механизм»).

## Сборка и инструменты

Сборщика у страницы нет: ES-модули + `importmap` (`three` → `vendor/three.min.js`).
Инструменты разработки лежат **вне репозитория**: `/Users/denisyudin/Documents/Codex/01_PUBLIC_SITE/liver-update-tools/`
(стенд рендера сцен, генератор постеров и OG-обложки, пересборка three.js, QA и замеры в headless Chrome; см. README там).

- three.js: `build/make-three.sh` собирает esbuild-ом бандл из классов, которые импортируют `gl/**/*.js`.
  После добавления нового импорта из `three` в сцену — пересобрать.
- Постеры: `node build/posters.mjs <liver-update>/posters <tmp> [regexp]` (рендер тем же движком, с подписями).
- При правке CSS/JS поднимать `?v=` у `styles.css` и `main.js` в `index.html` (модули ui/ и gl/ кэшируются на 10 минут).

## Лицензии

- three.js 0.186.1 — MIT (комментарий с лицензией в конце `vendor/three.min.js`).
- Literata (fonts.google.com, v40) — SIL OFL 1.1, без Reserved Font Name; файлы сужены по весам и знакам (см. `fonts/SOURCE.md`).
- IBM Plex Sans (v23) и IBM Plex Mono (v20) — SIL OFL 1.1, Reserved Font Name «Plex»; файлы не изменялись.
- Иконки: Lucide (ISC), game-icons.net (CC BY 3.0) — как в `/liver/`, атрибуция в подвале.
- 3D-геометрия процедурная, текстуры (кроме цифр на кружках, рисуемых на canvas) не используются;
  постеры и `cover.png` отрендерены этим же движком. Сторонних 3D-моделей и изображений нет.
- GSAP и Lenis не используются: переходы сделаны на CSS, rAF и View Transitions API — меньше веса, нативная прокрутка.
