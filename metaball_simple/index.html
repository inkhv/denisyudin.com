Жирность — радиус кисти в % от шага сетки: минимум — размер точки (кисть не тоньше точки), 50 % — соседние мазки только касаются, 100 % — край проходит по соседней точке. Скругление — радиус углов в % от жирности: 100 % — одна точка = круг, ряд = пилюля; 0 % — прямые углы. Контур всегда из прямых и дуг.
