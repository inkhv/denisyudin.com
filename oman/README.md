# Oman

Статическая подборка отелей Маската. Запрос: 17–23 ноября 2026, 2 взрослых, 1 номер, 6 ночей, завтраки, бюджет 170 992 ₽. Пользователь подтвердил зарубежную карту. Страница предназначена для прямой ссылки, не добавлена в индекс портфолио; стоит `noindex, follow`.

`index.html` содержит полноценный текст и исходные цены без JavaScript; `app.js` меняет условия отмены, расчётный курс, фильтр бюджета и порядок строк; `styles.css` изолирован. `data.json` содержит исходные проверенные суммы и ссылки. Фотографии взяты с официальных сайтов; происхождение сохранено в `assets/sources.json` и EXIF файлов.
